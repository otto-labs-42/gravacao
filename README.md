# gravacao.clonexlabs.com

Site do projeto de gravacao da Clonex, publicado via GitHub Pages.

O site inteiro esta em `index.html`, num arquivo so, com as imagens embutidas.
Para atualizar, suba um `index.html` novo por cima (Add file > Upload files).
O `CNAME` e o `.nojekyll` nao precisam ser mexidos.
